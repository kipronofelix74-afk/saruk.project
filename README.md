# Personal Project Showcase Application

A modern, responsive React application for creative agencies to showcase past work and dynamically add new project entries. Built based on the project mockup design.

## Features
- **Dynamic Project Addition:** Add new projects with custom titles and descriptions.
- **Live Search Filtering:** Instantly filter projects as you type in the search bar.
- **Responsive Design:** Styled using Tailwind CSS to seamlessly fit desktop and mobile screens.
- **Unit Tested:** Component behavior and state interactions verified with Vitest & React Testing Library.

## Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Testing:** Vitest & React Testing Library
